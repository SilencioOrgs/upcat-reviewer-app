# UPCAT Reviewer for Android

Offline study app for the UP College Admission Test: practice exams, a three-day review plan, a wrong-answer notebook, study techniques, a dictionary and a progress roadmap.

## Download

**[Download the latest APK](https://github.com/SilencioOrgs/upcat-reviewer-app/releases/latest/download/UPCAT-Reviewer.apk)** (all versions: [Releases](https://github.com/SilencioOrgs/upcat-reviewer-app/releases))

## Install

1. Open the link above on your Android phone and download the APK.
2. Open the downloaded file. If Android asks, allow installing apps from this source.
3. Open **UPCAT Reviewer**. No internet connection is needed after installing.

New versions install over the old one and keep your progress.

## Notes

- Practice questions are original and unofficial, and have not yet been reviewed by a teacher.
- This repository only hosts the app downloads.
